DPA購入ナビ v18（初回終了時刻の確認状態を明示する版）
============================================

目的
----
東京ディズニーランド／シーのDPA購入順を、過去の販売終了傾向から考えるための非公式PWAです。

今回の更新
----------
- v16で変更した集計値を採用せず、確認済みの旧集計値（v15）に戻しました。アナとエルサのフローズンジャーニーが夕方の18:45となるなど、日付別データとの整合性に疑問がある集計をそのまま使わないためです。
- 既存の日付別記録350件は削除せず保持しています。
- データ更新日を2026-10-30に更新し、アプリ／サービスワーカーのバージョンをv18にしました。

重要：時刻データの限界
----------------------
この既存データの「observedEndTime」は、観測時点で販売中でなくなった時刻を記録したものです。過去の全記録について「その日の最初の販売終了」だったと確認できているわけではありません。再販後に再び販売終了した時刻が混ざっている可能性を、既存データだけから判別することもできません。

そのため、この版では初回販売終了時刻と確認済みであるかのように過去データを書き換えていません。購入順を考えるという目的には初回販売終了時刻が適切ですが、初回終了時刻だと確認できない記録は、今後、根拠のある観測データと照合して段階的に整理する必要があります。再販や最終販売終了時刻を購入順の根拠として当てにしないでください。

データと注意点
--------------
- data/dpa-history.json を共有データとして使います。
- 既存の日付別記録は「販売中でなくなった時刻」で、売り切れと当日の販売受付終了を厳密には区別できません。
- 集計中央値は旧版の値を保持していますが、それも初回販売終了時刻だけで構成されていると保証できるものではありません。参考値として扱ってください。
- 実際の購入可否は、必ず公式アプリの最新表示を確認してください。
- このZIPでは出典名と出典URLの表示・項目を含めていません。これはデータの利用許諾や権利関係を保証するものではありません。公開・配布前に、使用するデータの利用条件を確認してください。

GitHub Pagesへの公開・更新
-------------------------
1. ZIPを展開します。
2. index.html、app.js、sw.js、manifest.json、icons/、data/ をGitHubリポジトリの公開ルートへ配置します。フォルダ構成を保ってください。
3. GitHub Pagesの公開設定を確認します。
4. 公開URLでパーク切替、検索、ランキング、データ更新日の表示を確認します。
5. 古い画面が残る場合は再読み込みしてください。サービスワーカーのキャッシュ名は dpa-purchase-navi-v18 です。

今後のデータ更新
----------------
初回販売終了時刻を新たに記録する際は、販売中から販売終了へ変わった最初の時刻を確認してください。再販後の最終終了時刻で置き換えず、初回終了時刻が確認できない場合は推測で補完しないでください。同じ日付・パーク・施設の重複を避け、JSON形式を検証してから更新します。

このツールは非公式です。購入・利用可否は公式アプリの最新表示を確認してください。


v18でのデータ監査対応
- 日別350件は1件も削除せず保持しています。
- 全350件に timeMeaning=unverified_first_end / firstEndVerified=false を付与しました。これは「初回終了ではない」と断定する意味ではなく、「初回終了だと確認できていない」という意味です。
- 既存の集計14件も保持し、初回終了時刻のみの集計と確認できないため参考値として明示しました。
- 現時点の初回終了確認済み記録は0件です。公開サイトにある集計値は集計方法や対象日の違いがあり、個々の日の初回終了時刻の証拠として流用していません。
- 将来、初回終了時刻を確認できた記録は別分類で追加し、確認済みデータと未確認データを混ぜない方針です。
