DPA購入ナビ（改修版）
====================

目的
----
「何時に売り切れるか」を断定するのではなく、東京ディズニーランド／シーのDPA購入を考える際に、過去の販売終了傾向を早い目安順で比較するPWAです。

今回の主な改修
--------------
- アトラクションを1件ずつ選ぶ画面をやめ、パーク内の対象施設を一覧で比較する画面に変更。
- 予測確率の表示を削除。日付別記録が「売り切れ」と「当日の販売受付終了」を区別していないため、確率として扱わない。
- 過去の集計中央値を優先し、集計がない施設は日付別記録から参考中央値を計算。
- 各施設に根拠の種類・集計対象日数／使用記録数を表示し、目安を出せない施設は推測せず「目安なし」と表示。
- 日付、パーク、施設名検索、曜日区分（自動／平日／土日祝日）を一画面に集約。
- 祝日は自動判定しないことを明示。祝日や混雑日を想定する場合は「土日祝日として見る」を選択。
- サービスワーカーを更新し、共有データJSONはネットワークを優先、オフライン時のみキャッシュへフォールバックする設計に変更。
- 不要な確率メーターや一施設だけの予測操作を削除し、判断に必要な情報を優先。

収録データと読み方
------------------
data/dpa-history.json を共有データとして使います。初期データの更新日、件数、出典は画面の「データの根拠と注意点」に表示されます。

優先順位は、選択した曜日区分に合う公開集計の中央値がある施設ではその値を使い、ない場合は日付別記録の中央値を参考として使います。時刻が早い順に並びます。これは売り切れ時刻の予測や現在の販売状況の表示ではなく、購入順を考えるための参考です。

重要な制約
----------
- 日付別記録は「販売中でなくなった時刻」で、売り切れと当日の販売受付終了を区別しません。また、販売中でなくなった記録が中心のため、販売終了しなかった日を含む全日平均とは限りません。売り切れ確率は表示しません。
- 集計中央値と日付別記録は別物として扱い、集計値を日付別記録に変換しません。
- 「土日祝日」はユーザーが選ぶ区分であり、祝日カレンダーによる自動判定は行いません。
- 予測順位は過去データに基づく目安です。対象施設、販売条件、当日の需要、システム状況などで実際の販売状況は変わります。
- データ更新日や件数が新しくても、元データの取得範囲・定義の限界は残ります。公式アプリの表示を必ず優先してください。
- GitHub Pagesだけでは外部サイトの定期巡回や自動更新は行いません。共有JSONを更新するには、更新した data/dpa-history.json をリポジトリへコミットする必要があります。

GitHub Pagesへの公開・更新
-------------------------
1. ZIPを展開します。
2. index.html、app.js、sw.js、manifest.json、icons/、data/ をGitHubリポジトリの公開ルートへアップロードします。フォルダ構成を保ってください。
3. GitHubリポジトリの Settings > Pages で公開設定を確認します。
4. 公開URLをスマートフォン／PCで開き、日付・パーク切替、検索、ランキング、データ更新日の表示を確認します。
5. 既にインストール済みの場合、古い画面が残る場合はページを再読み込みしてください。新しいサービスワーカーのキャッシュ名は dpa-purchase-navi-v6 です。

データの更新
------------
1. 既存の data/dpa-history.json を保存し、更新元として使います。
2. 公開ソースを確認して、取得できた記録のみ追加します。日付・パーク・施設ID・状態・時刻・出典URL・確認日を保持してください。
3. 同じ日付・パーク・施設の重複を避け、確認できなかった値を推測で埋めないでください。
4. 更新後のJSONを同じパスに置き換えてコミットします。画面は共有JSONを参照します。
5. 更新時は、出典サイトの定義や集計方法が変わっていないかも確認してください。

テストチェックリスト
--------------------
- [ ] 初回ロード後、データ更新日と件数が表示される
- [ ] 東京ディズニーランド／シーを切り替えると対象施設が切り替わる
- [ ] 来園日と曜日区分の変更で時刻順が更新される
- [ ] 施設名検索で一覧を絞り込める
- [ ] 時刻データのない施設に時刻を捏造せず「目安なし」と表示される
- [ ] ネットワーク接続時に共有JSONの最新版を取得できる
- [ ] オフライン時にキャッシュがあれば画面を表示できる
- [ ] スマートフォン幅で操作・文字表示に問題がない
