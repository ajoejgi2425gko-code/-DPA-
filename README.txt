DPA購入ナビ v15（祝日自動判定・出典表示整理版）
============================================

目的
----
東京ディズニーランド／シーのDPA購入を考える際に、登録済みの過去データから購入順を考えるための目安を表示するPWAです。実際の売り切れ時刻や現在の販売状況を保証するものではありません。

主な機能
--------
- パーク内の対象施設を一覧で比較
- 来園日・パーク・施設名で絞り込み
- 日本の祝日をアプリ内で自動判定
- 祝日以外の混雑予想日は「土日祝日として見る」を手動選択可能
- データの更新日と鮮度に関する注意表示
- データがない施設は推測せず「目安なし」と表示
- お子さまの身長に応じた利用条件の目安表示

データと注意点
--------------
- data/dpa-history.json を共有データとして使います。
- 日付別記録は、販売中でなくなった時刻を示すもので、売り切れと当日の販売受付終了を厳密には区別できません。
- 記録の件数が多いことだけで、予測の正確さが保証されるわけではありません。
- 実際の購入可否は、必ず公式アプリの最新表示を確認してください。
- このZIPでは出典名と出典URLの表示・項目を含めていません。これはデータの利用許諾や権利関係を保証するものではありません。公開・配布前に、使用するデータの利用条件を確認してください。

GitHub Pagesへの公開・更新
-------------------------
1. ZIPを展開します。
2. index.html、app.js、sw.js、manifest.json、icons/、data/ をGitHubリポジトリの公開ルートへ配置します。フォルダ構成を保ってください。
3. GitHubリポジトリの Settings > Pages で公開設定を確認します。
4. 公開URLをPC／スマートフォンで開き、パーク切替、検索、ランキング、データ更新日の表示を確認します。
5. 古い画面が残る場合は再読み込みしてください。サービスワーカーのキャッシュ名は dpa-purchase-navi-v15 です。

データ更新
----------
1. 既存の data/dpa-history.json をバックアップします。
2. 新しい記録を追加する場合、日付・パーク・施設ID・状態・時刻・確認日を正しい形式で記録します。
3. 同じ日付・パーク・施設の重複を避け、確認できなかった値を推測で埋めないでください。
4. JSONの形式を検証し、同じパスのファイルを更新してコミットします。
5. 更新後、公開アプリでデータ読み込みと表示を確認します。

確認項目
--------
- [ ] 初回ロード後、データ更新日と件数が表示される
- [ ] ランド／シーを切り替えると対象施設が切り替わる
- [ ] 来園日と曜日区分の変更で時刻順が更新される
- [ ] 施設名検索で一覧を絞り込める
- [ ] 時刻データのない施設に時刻を捏造せず「目安なし」と表示される
- [ ] ネットワーク接続時に共有JSONの最新版を取得できる
- [ ] オフライン時にキャッシュがあれば画面を表示できる
- [ ] スマートフォン幅で操作・文字表示に問題がない

このツールは非公式です。購入・利用可否は公式アプリの最新表示を確認してください。
